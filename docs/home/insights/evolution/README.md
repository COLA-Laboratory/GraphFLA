# Directed-evolution benchmark data

This directory contains a feature and optimization-outcome dataset for 18 empirical protein amino-acid landscapes in `data/BioSequence`. Each landscape retains every genotype row in its source CSV; missing combinations are not imputed. `sources.json` records the study citation, assay, score direction, source-file hash, genotype coverage, and any dataset-specific note. The scatter outcome is the mean best-fitness percentile across 10 fixed seeds. A percentile is the fraction of observed genotypes whose score is less than or equal to the best measured score, so ties share a rank and the observed maximum is 1.

The four strategies share a 96-genotype random starting set per seed. RF greedy and RF uncertainty-guided then select four batches of 96 unique observed genotypes using a 32-tree RandomForestRegressor with one-hot amino-acid features (`max_features="sqrt"`, `max_depth=10`, bootstrap enabled, one CPU). The forest is refit to standardized observed scores after each batch. RF greedy ranks by the predictive mean; uncertainty-guided ranks by standardized predictive mean plus one between-tree standard deviation. Random search samples 480 unique genotypes. Greedy directed evolution starts at the first shared initial genotype and moves to the best improving observed one-site neighbor; it stops at a local optimum or after at most 480 queries. `simulation_runs.csv` preserves the per-seed endpoint and exact number of unique queries. TEV and T7 use the repository-supplied scores without transformation; their outcomes are within-table percentiles.

Landscape features use the full retained one-edit graph (`epsilon=0`), with no neutrality feature. They include magnitude, sign, and reciprocal-sign epistasis; diminishing returns; increasing costs; global idiosyncratic effects; roughness-to-slope; gamma and gamma-star; local optima; autocorrelation; fitness-distance correlation; evolvability-enhancing fraction; and global-optimum accessibility. Gamma and gamma-star pool observed complete two-variable squares, omit incomplete corners, and apply GraphFLA's equal allele-pair weighting. Epistasis-classification sampling uses `sample_cut_prob="auto"`, seed 20261004, and a 15-second time budget. Diminishing-returns and increasing-costs indices use their default Pearson trend definitions; the global idiosyncratic index uses `n_jobs=1`, seed 20261004, and `min_pairs=3`. Autocorrelation uses 1,000 walks of length 20 at lag 1, seeded 20261004; fitness-distance correlation uses Spearman rank correlation. The evolvability-enhancing fraction uses FDR 0.01 and all effect types, without neutrality or experimental-error inputs. Other features use the GraphFLA analysis defaults. The preparation script computes these features sequentially and fixes numerical-library thread counts to one.

Run `.venv-ci39/bin/python docs/home/insights/evolution/preparation.py` from the repository root to compute the full bundle. The script saves detailed per-landscape feature records under `.codex-local/insights/evolution/`, then atomically refreshes `data.json`, `sources.json`, and `simulation_runs.csv`. Use `--export-only` to rebuild those public files from the existing detailed records and seed-level runs.
